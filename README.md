# FRAME//ZERO v42 — Duo Stable

Stabilitätsbuild auf Basis v41 mit konservativem Rendering für iOS/WebKit: alle dauerhaften flächigen Animationen und GPU-Backdrops deaktiviert, nur kurze Timer-Ein-/Ausblendung bleibt. Fixierte Navigation, modal-sichere Überlagerung, neues Offline-Cache-Namespace. Vor Aktualisierung JSON-Backup erstellen.

**Hinweis:** Das Aussehen der Glasflächen ist absichtlich weniger verschwommen, um auf iOS flackerfreie Darstellung zu priorisieren.
